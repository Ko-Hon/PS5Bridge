# 游界桥使用说明

游界桥在 Mac 上运行，将同一局域网内选定设备的 IPv4 TCP/UDP 流量经 Mac 上的隧道接口转发。当前界面以 PS5 为目标，一次只能转发一台设备。

**操作顺序：先在 Mac 用 Shadowrocket（小火箭）连接 VPN → 再开启游界桥转发 → 最后将 PS5 的默认网关设为 Mac。**

需要自行准备客户端和可用节点。游界桥使用 Mac 已经建立的 VPN／TUN 出口，使用期间客户端与游界桥都必须保持运行。

## 开始前

- 使用 Apple Silicon Mac，并保持唤醒。
- Mac 与 PS5 连接同一路由器的普通 Wi-Fi；不要使用设备隔离的访客网络。
- **先在 Mac 打开 Shadowrocket，配置可用节点并开启 VPN／TUN 连接**，确认 Mac 能通过该出口访问目标服务。首次验证可选择全局代理模式；游戏所用节点需支持相应 UDP 流量。
- 当前出口客户端实测为 Shadowrocket。其他 SSR／代理客户端需要提供兼容的 macOS `utun` 隧道接口，单独开启 HTTP／SOCKS 系统代理不够；其他客户端尚未逐一验证。
- 不要同时开启 macOS 互联网共享或其他内核网关软件；检测到系统内核转发已开启时，游界桥会拒绝启动。
- 建议在路由器中为 Mac 和 PS5 预留固定 IPv4 地址。

## 配置并启动

以下步骤以 **Mac 上的 Shadowrocket VPN 已连接并可用** 为前提：

1. 在 PS5 的“设置 → 网络 → 连接状态 → 查看连接状态”记录当前 IPv4 地址与子网掩码。
2. 打开游界桥，切换到“设置”，展开“配置 Mac”。
3. 选择与 PS5 处于同一局域网的接口，填写刚才记录的 PS5 IPv4 地址。不要填路由器或 Mac 的地址。
4. 可先在“诊断与日志”中运行“检测转发权限”，检查 BPF、降权和出口绑定。该检测本身不启动设备转发。
5. 点击顶部“开始转发”。出现 macOS 管理员验证弹窗时，由你在系统窗口中完成验证。
6. 在“设置 → 设置 PS5”中查看网关与其他参数，然后在 PS5 当前连接的高级设定中手动填写。
7. PS5 默认网关填写 **Mac IPv4**，DNS 填可用的公共 DNS，MTU 自动，代理服务器“不使用”。
8. 在 PS5 打开 YouTube 或游戏，切换到“监控”查看状态、速率、流量和目标服务器。

监控和设置之间切换不会停止转发或清零统计。点击卡片整条标题栏可折叠或展开，内容区中的按钮和输入框各自独立操作。

## 状态灯与测量

| 项目 | 绿色含义 |
| --- | --- |
| PS5 | 局域网 Ping 可达，或最近 30 秒收到该设备的转发流量 |
| Mac | 局域网配置有效，转发引擎运行且心跳正常 |
| 网络出口 | 经选定出口的 Google HTTPS 检测成功；Ping 作为辅助 |

状态灯不能证明所有游戏服务器都可用。设备也可能不回应 Ping，却仍在正常通讯。出口检测会复核短暂失败，减少瞬时闪烁。

Google HTTPS 是完整请求耗时；TCP 建连时间与目标 Ping 各有不同含义，都不等于游戏内延迟。连接列表最多展示 12 个目标，域名不可见时保留 IP。若客户端使用 Fake IP，显示地址可能是合成地址。

## DNS、地址和 IPv6

- DNS 不强制使用 `1.1.1.1` 和 `8.8.8.8`。它们只是界面示例，转发引擎不限制 DNS 目标地址。
- 同网段路由器的 DNS 地址可能让查询直接发送给路由器；若希望 DNS 查询也经 Mac 转发，可使用可用的公共 DNS。
- PS5 地址变化后需要停止转发、更新软件中的地址，再重新开始。
- Mac 局域网地址变化时，软件会停止转发，需要同步修改 PS5 网关。
- 当前不处理 IPv6；如果对应网络提供 IPv6，这部分流量可能直接走原路由器。

## 手机可以用吗

引擎按目标 IP 转发，没有限制必须是 PS5。可把目标换成手机的 IPv4，并将手机的 Wi-Fi 默认网关设为 Mac。手机无需安装游界桥；Mac 端仍需保持应用和出口客户端运行。

当前手机接入尚未完成实机验证，而且不能与 PS5 同时转发。测试时可关闭蜂窝数据，避免移动网络影响判断。手机自身的代理、IPv6 和其他网络功能也可能改变实际路径。

## 停止使用

点击“停止转发”，再把设备的 IP 与 DNS 设定恢复为自动。退出游界桥同样会结束转发；如果设备仍把 Mac 当作网关，外网连接可能中断。

## 常见排查

- **只打开游界桥仍不能访问目标服务**：先在 Mac 连接并验证 Shadowrocket VPN，保持连接后再开始转发；软件依赖这个已有出口。
- **管理员验证没完成**：在 macOS 系统弹窗中完成验证后重新开始；不要把管理员密码发到聊天或问题反馈中。
- **没有设备流量**：检查目标 IP、子网掩码和网关，确认 Mac 与设备没有被 Wi-Fi 客户端隔离。
- **有上传没有回包**：先确认 Mac 的出口确实可达，再检查节点与目标协议支持情况。
- **游戏联机失败**：UDP、NAT 类型、服务器规则和上游节点能力都可能影响；本工具不提供入站端口映射。
- **数值高或速度慢**：比较 Mac 经相同节点的表现，检查 Wi-Fi 干扰、下载占用和节点负载。没有经过基准测试的固定加速幅度。
- **退出后设备不能上网**：把设备 IP、网关与 DNS 恢复为自动。

诊断导出只在你主动导出时生成；其中可能含局域网地址、目标域名和端口，公开分享前先检查内容。
